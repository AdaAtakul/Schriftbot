# Schriftbot-Assistent (Claude-Artifact)

Quelltext der Seite, die unter https://claude.ai/artifact/L4y3bjCy9kEdLnYdMK1k5j als Claude-Artifact läuft.
Sie fragt Claude über die `sample`-Fähigkeit von claude.ai – mit dem Konto der Person, die sie öffnet, ohne API-Schlüssel –
und kopiert die Antwort nach Bestätigung in die Zwischenablage. Die Handschrift-App fügt sie mit „Claude-Antwort einfügen“ ein.

Diese Datei gehört nicht zur App (wird nicht von GitHub Pages benutzt); sie liegt hier nur als Sicherung und zum Weiterentwickeln.
